# NSM primary sources override the threshold.works model

The planner was ported from the threshold.works Plan Generator (`docs/research/threshold-works-model.md`), but where that model disagrees with the method's primary sources (norwegiansingles.run and sirpoc's posts, see `docs/research/nsm-rationale.md`) the planner follows the sources. This is why it differs from threshold.works in its 5-9h Weekly Duration range, always three Sub-threshold Sessions, Recoveries set by Rep Length, a Long Run of about 1.7 times an Easy Run, and a Sub-threshold Share that eases from 23% to 20% above 7h. Rules the sources neither support nor contradict (the 23% target, the 35-minute session cap, merging short Easy Runs) stay as planner choices and are labelled as such on the How this works page.
