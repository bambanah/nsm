## Pull requests

- When a PR changes what the user sees, screenshot the affected view before and after the change (the `screenshots` skill covers how) and attach both with `gh pr create --attach` (or `gh pr edit --attach`). Reference each file in the template's Evidence section as `![Before](./before.png)` so gh rewrites the link in place rather than appending the image to the end of the body. Save the screenshots outside the repo.
